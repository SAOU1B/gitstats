# Contributing to gitstats

Thank you for helping! This project follows the GitHub flow.

1. **Open an issue** first (use the *Bug report* template for bugs).
2. **Create a branch** from `main` with a descriptive name, e.g. `fix-empty-repo`.
3. **Keep commits small** and write messages in the imperative mood ("Add …", "Fix …").
   Run `git diff --check` before committing to catch whitespace errors.
4. **Run the tests**: `python test_gitstats.py`.
5. **Open a pull request** that references the issue (`Closes #N`). The *tests* workflow
   runs automatically on Ubuntu and Windows and must pass before merging.
